## Proyecto destacado: Netto 🚕

Aplicación web para taxistas que permite registrar viajes,
consultar la recaudación y calcular la liquidación entre
conductor y empresa según los cobros en efectivo y con tarjeta.

En este proyecto he trabajado en:

- Una interfaz adaptable a móvil con React y Tailwind CSS.
- Autenticación, recuperación de contraseña y edición del perfil.
- Historial de viajes con filtros, paginación y gráficas.
- Acceso a los datos de cada usuario mediante políticas RLS.
- Envío de correos con Supabase Edge Functions y Resend.
- Pruebas de cálculos, autenticación y rutas protegidas.
- Comprobaciones automáticas con GitHub Actions y despliegue en Vercel.

**Stack:** React · JavaScript · TypeScript · Supabase · Tailwind CSS · Vitest
